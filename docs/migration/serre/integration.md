# Main-library integration of connective Serre localization

## Complete public entry points

The integration registers four complete mathematical items, with ordinary
supporting lemmas retained at their native owners:

- COL-0247: homotopy invariance of arbitrary filtered realization.
- COL-0248: full Quillen Theorem B with both actual comma-to-fiber comparisons.
- COL-0249: the canonical Serre localization fiber weak equivalence.
- COL-0250: the complete canonical connective localization sequence and boundary.

Theorem B assumes actual transition homotopy equivalences. It is not the more
general weak-transition variant of the implementation source. The filtered
result is attributed to its exact pinned Quillen source, not to a sequential
union passage. The Serre items retain the original small abelian/Serre
hypotheses and actual maps. Existing sequential and algebraic K-zero items keep
their narrower scopes. The bibliography uses existing versioned source records.

The eight tagged production files retain every byte of their reviewed source
as a prefix. Only native catalog/reference attributes and a namespace block
for those attributes are appended. `integration-source-crosswalk.json` records
both the reviewed prefix and current source hashes. These metadata additions
are not represented as new mathematical proofs or new independent review.
